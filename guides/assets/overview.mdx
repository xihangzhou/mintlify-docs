Open API **assets** are resources you create and reference by ID in task requests. There are two types:

| Asset | ID field | Purpose |
|-------|----------|---------|
| **Material** | `materialId` | Uploaded video or audio used as input (mainly media translation) |
| **Voice** | `voiceId` | System preset or cloned voice used in TTS |

## Isolated from Dashboard

Open API **assets and tasks** use a separate store from the Dashboard UI — they are not interchangeable.

### Assets

API assets are **not shared** with Dashboard **My assets**:

- Materials uploaded via `/openapi/assets/material/**` do **not** appear in the Dashboard file library.
- Cloned voices created via the API do **not** appear in Dashboard voice management UI.
- The reverse is also true — Dashboard uploads are **not** available as Open API `materialId` values.

Manage API materials and voices only through Open API asset endpoints.

### Tasks

Tasks created via the Open API **do not** appear in Dashboard **My tasks**, and Dashboard tasks are **not** listed by `/openapi/tasks/**`. See [Products overview](/guides/products/overview#isolated-from-dashboard-tasks).

## Typical flow

```text
Upload material → materialId → media translation task
Voice clone task → voiceId → TTS task
List basic voices → voiceId → TTS task
```

The VMEG Open API lets you run speech and translation workloads programmatically: submit tasks, manage API-scoped assets, and receive async results via webhooks.

## Conventions

| Topic | Detail |
|-------|--------|
| Base URL | `https://api.vmeg.ai` |
| Authentication | `Authorization: Bearer <api_key>` on every `/openapi/**` request — see [Auth](/guides/authentication) |
| Response envelope | `{ "code", "message", "data" }` — business success when `code === 200` |
| `extraData` | Optional object on task requests; echoed in webhook callbacks for your correlation IDs |
| Languages | Locale codes such as `en-US`, `zh-CN` — see [Supported languages](/guides/supported-languages) |
| API scope | Open API tasks and assets are separate from Dashboard **My tasks** and **My assets** — see [Products overview](/guides/products/overview) and [Assets overview](/guides/assets/overview) |

## Integration path

```text
Auth → Pricing (credits) → Quickstart (sync TTS)
     → Idempotency + Webhooks (async)
     → Assets (materialId / voiceId)
     → Products
```

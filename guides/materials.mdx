Tasks such as media translation require a **materialId**. Upload files via presigned URLs to object storage, then call the complete endpoint to register and process the asset.

You can also manage files in the product under <a href={productUrls.myAssets}>My assets</a>.

## Single-file upload

<Steps>
  <Step title="Get a presigned URL">
    `POST /openapi/assets/material/upload/gen-upload-url`

    ```json
    { "fileHash": "<md5>", "fileName": "demo.mp4" }
    ```

    Response `data` includes the upload URL, `uploadId`, and related fields.
  </Step>
  <Step title="PUT file to CDN">
    Upload bytes to the returned URL (not through the VMEG API gateway).
  </Step>
  <Step title="Complete upload">
    `POST /openapi/assets/material/upload/complete`

    The server processes metadata and returns `OpenApiMaterialDto` including `materialId`.
  </Step>
</Steps>

## Multipart upload (large files)

1. `POST .../multipart/initiate` — start session
2. `POST .../multipart/presign-parts` — presigned URLs per part number
3. Upload each part
4. `POST .../multipart/complete` — finalize and register
5. On failure, `POST .../multipart/abort` — abort session

## List and delete

- List: `GET /openapi/assets/material/list?projId=...`
- Delete: `POST /openapi/assets/material/delete` (logical delete)

## Use with media translation

Pass `materialId` in `source.materialId` on your [media translation](/guides/media-translation) request.

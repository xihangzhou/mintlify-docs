## API Key

All endpoints under `/openapi/**` require an **API Key**.

```http
Authorization: Bearer <your_api_key>
```

The server resolves the key to a `projId` (project ID). List and detail calls that accept `projId` must match the project bound to the key.

<Warning>
  Do not expose API Keys in client apps or public repositories. Store keys in environment variables or a secrets manager.
</Warning>

## Create and rotate keys

Create and rotate keys on <a href={apiKeyUrl}>API Configuration</a> in the Dashboard (sidebar **API**). <a href={productUrls.signInToApiSettings}>Sign in</a> if needed.

The same page configures your **Webhook URL** and **Webhook Secret** for async callbacks.

<Info>
  API Configuration is available on paid plans. See [Pricing](/guides/pricing).
</Info>

## Authentication failures

HTTP status `401` with a JSON body such as:

```json
{
  "code": 401,
  "message": "Invalid or missing API Key",
  "data": null
}
```

See [Error codes](/guides/errors) for the full code list.

## What you need for integration

| Path | Auth | Purpose |
|------|------|---------|
| `/openapi/**` | Bearer API Key | Your integration |
| Dashboard `/api/openapi/**` | Session JWT | Product UI only |

For server-to-server integration you typically need `/openapi/**` plus a [Webhook receiver](/guides/webhooks).

Every Open API **product** creates a **task** with a `taskId`. You can list, inspect, and delete tasks through shared task endpoints regardless of product type.

## Isolated from Dashboard tasks

Open API tasks are **managed separately** from tasks you submit in the Dashboard — the same isolation model as [API assets](/guides/assets/overview).

- Tasks created via `/openapi/task/**` or listed with `/openapi/tasks/**` **do not** appear in Dashboard **My tasks**.
- Dashboard jobs are **not** visible through Open API task list or detail endpoints.
- Use only the Open API task endpoints (and webhooks) to track API-submitted work.

<Info>
  **API scope** = API Key + `projId` + Open API tasks and assets. Dashboard UI uses a separate task and asset store for in-product workflows.
</Info>

## Task APIs

| Action | Endpoint |
|--------|----------|
| List | `GET /openapi/tasks/list` |
| Detail | `GET /openapi/tasks/detail` |
| Delete | `POST /openapi/tasks/delete` |

Schemas: **API reference → Tasks**.

## Sync vs async

| Product | Sync create | Async create | How you get results |
|---------|-------------|--------------|---------------------|
| [Text to speech](/guides/products/text-to-speech) | `POST .../tts/create` | `POST .../tts/create-async` | Sync: `data.results` in HTTP response. Async: [Webhook](/guides/webhooks) |
| [Text translation](/guides/products/text-translation) | `POST .../translate/create` | `POST .../translate/create-async` | Sync: `data.items` in response. Async: Webhook |
| [Voice clone](/guides/products/voice-clone) | `POST .../clone-voice/create` | `POST .../clone-voice/create-async` | Sync: `voiceId` in response. Async: Webhook |
| [Media translation](/guides/products/media-translation) | — | `POST .../media-translation/create-async` | Async only: Webhook |

### Async integration checklist

1. [Auth](/guides/authentication) — API Key
2. [Idempotency](/guides/idempotency) — `X-Idempotency-Key` on every `create-async`
3. [Webhooks](/guides/webhooks) — URL + secret; return 2xx quickly
4. Submit `create-async` → save `taskId`
5. Handle [Webhook request body](/guides/webhook-request) on `task.completed`

### Sync integration

Call `create` (non-async) and read results from the HTTP `data` payload. An idempotency header is optional on sync endpoints.

## Task types

| `taskType` | Product |
|------------|---------|
| `TTS` | Text to speech |
| `TEXT_TRANSLATION` | Text translation |
| `CLONE_VOICE` | Voice clone |
| `VIDEO_TRANSLATION` / `AUDIO_TRANSLATION` | Media translation |

`SUBTITLE_TRANSLATION` exists in the type enum but is **not** exposed as a separate Open API product at this time.

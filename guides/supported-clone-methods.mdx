Pass a **`provider`** value of `V1` through `V5` to choose the voice clone / synthesis engine. These codes match the clone model options on [vmeg.ai](https://www.vmeg.ai/home) for video translation and voice cloning.

## Where to set `provider`

| Product | Field |
|---------|--------|
| [Text to speech](/guides/products/text-to-speech) | **Do not send** `provider`; inferred from each `data[].voiceId` |
| [Voice clone](/guides/products/voice-clone) | `provider` when creating a cloned voice |
| [Media translation](/guides/products/media-translation) | `options.voiceClone.provider` when voice cloning is enabled |

## Engine versions

| `provider` | Model | Best for |
|------------|-------|----------|
| `V1` | Basic universal | Simple cloning — short sentences, everyday dialogue |
| `V2` | Film & TV emotional | Films, dramas, storytelling — emotional shifts and tone detail |
| `V3` | English-focused | General use with more accurate, natural cloning for **English** voices |
| `V4` | Enhanced emotional | Authentic emotion and subtle mood changes; strongest nuance |
| `V5` | Multilingual universal | **Non-English** and multilingual voices |

## Choosing a version

| Your content | Suggested `provider` |
|--------------|---------------------|
| Short lines, light usage | `V1` |
| Drama, film, strong performance | `V2` or `V4` |
| Mostly English source/target | `V3` |
| Mostly non-English or multilingual | `V5` |

## Text to speech: `voiceId` and provider

[Text to speech](/guides/products/text-to-speech) accepts up to 50 lines in `data[]` per request. **You do not need to send `provider`.** The server looks up each `data[].voiceId` in the [system voice](/api-reference/assets/voices/list-system-voices) or [cloned voice](/api-reference/assets/voices/list-cloned-voices) library, infers `provider`, and passes it to the synthesis engine (any `provider` in the request body is ignored).

Batch rules:

**Every `voiceId` must exist.** If a ID is missing from both libraries, the API returns `400` and points you to `POST /openapi/v1/assets/voice/basic/list` or `POST /openapi/v1/assets/voice/clone/list`.

**All `voiceId`s in one batch must resolve to the same `provider`** (system or clone). For example, you cannot combine a `Microsoft` system voice with a `GC` system voice, or a `V1` clone with a `V2` clone, in one request. On mismatch, the API returns `400` with a `voiceId` → `provider` mapping.

**`timbreRefAudio` is clone-only.** If any line uses `timbreRefAudio`, the inferred provider must be a clone engine (`V1`–`V5`). Do not mix `timbreRefAudio` with system `voiceId`s in the same batch.

See [Error codes](/guides/errors) → **TTS voice validation** for exact `message` strings.

<Note>
  Locale codes for languages are listed separately in [Supported languages](/guides/supported-languages). `provider` selects the **clone engine**, not the language.
</Note>

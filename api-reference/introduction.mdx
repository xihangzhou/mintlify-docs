API reference pages are generated from our published [OpenAPI 3.1](https://mintlify.com/docs/api-playground/openapi/setup) specification.

## URLs

| Purpose | URL |
|---------|-----|
| Documentation site | [https://docs.vmeg.ai/api](https://docs.vmeg.ai/api) |
| API base URL (all `/openapi/**` requests) | `https://api.vmeg.ai` |

The interactive Playground sends requests to `https://api.vmeg.ai`.

## Authentication

All `/openapi/**` endpoints use a Bearer API Key. Enter your key in the Playground to try requests.

## Endpoint groups

| Group | Description |
|-------|-------------|
| TTS | Speech synthesis (sync and async) |
| Text translation | Batch sentence translation |
| Voice clone | Clone from reference audio |
| Media translation | Video/audio localization pipeline |
| Task management | List, detail, delete |
| Assets - Materials | Upload and material library |
| Assets - Voices | System and cloned voices |

Concept guides (idempotency, webhooks, errors) are under the **Guides** tab.

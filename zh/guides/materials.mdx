媒体翻译等任务需要 **materialId**。通过预签名 URL 直传对象存储，再调用完成接口注册并处理资产。

也可在产品 <a href={productUrls.myAssets}>我的素材</a> 中管理文件。

## 单文件上传

<Steps>
  <Step title="获取预签名 URL">
    `POST /openapi/assets/material/upload/gen-upload-url`

    ```json
    { "fileHash": "<md5>", "fileName": "demo.mp4" }
    ```

    响应 `data` 包含上传 URL、`uploadId` 等字段。
  </Step>
  <Step title="PUT 上传到 CDN">
    将文件字节上传到返回的 URL（不经过 VMEG API 网关）。
  </Step>
  <Step title="完成上传">
    `POST /openapi/assets/material/upload/complete`

    服务端处理元数据并返回含 `materialId` 的素材信息。
  </Step>
</Steps>

## 分片上传（大文件）

1. `POST .../multipart/initiate` — 开启会话
2. `POST .../multipart/presign-parts` — 按分片号获取预签名 URL
3. 上传各分片
4. `POST .../multipart/complete` — 完成并注册
5. 失败时 `POST .../multipart/abort` — 中止会话

## 列表与删除

- 列表：`GET /openapi/assets/material/list?projId=...`
- 删除：`POST /openapi/assets/material/delete`（逻辑删除）

## 用于媒体翻译

在 [媒体翻译](/zh/guides/media-translation) 请求的 `source.materialId` 中传入 `materialId`。

VMEG Open API 支持以编程方式运行语音与翻译任务：提交任务、管理 API 侧资产，并通过 Webhook 接收异步结果。

## 约定

| 主题 | 说明 |
|------|------|
| Base URL | `https://api.vmeg.ai` |
| 鉴权 | 每个 `/openapi/**` 请求携带 `Authorization: Bearer <api_key>` — 见 [鉴权](/zh/guides/authentication) |
| 响应结构 | `{ "code", "message", "data" }` — 业务成功时 `code === 200` |
| `extraData` | 任务请求中的可选对象；Webhook 回调中原样回传，便于业务关联 |
| 语言 | 区域代码如 `en-US`、`zh-CN` — 见 [支持的语言](/zh/guides/supported-languages) |
| API 范围 | Open API 任务与资产与 Dashboard **我的任务**、**我的素材** 隔离 — 见 [产品概览](/zh/guides/products/overview) 与 [资产概览](/zh/guides/assets/overview) |

## 集成路径

```text
鉴权 → 价格（积分）→ 快速开始（同步 TTS）
     → 幂等 + Webhook（异步）
     → 资产（materialId / voiceId）
     → 产品
```

音色仅属 API 侧，TTS 通过 `voiceId` 引用，与 vmeg.ai 网页上的音色不互通。见 [资产概览](/zh/guides/assets/overview)。

## 两类音色

| 类型 | 来源 | API |
|------|------|-----|
| **系统（basic）** | 平台预设 | `POST /openapi/assets/voice/basic/list` — 只读 |
| **克隆（cloned）** | [声音克隆](/zh/guides/products/voice-clone) 成功 | `POST /openapi/assets/voice/clone/list`、`update`、`delete` |

## 系统音色

列出可用预设，选取 `voiceId` 用于 [文本转语音](/zh/guides/products/text-to-speech)。

筛选与响应字段：[列出系统音色](/api-reference/assets/voices/list-system-voices)。

## 克隆音色

声音克隆成功（同步响应或异步 Webhook）后，VMEG 持久化克隆并分配新 **`voiceId`**，可用于后续 TTS。

可通过 clone 资产接口重命名或逻辑删除。请求与响应字段：[列出克隆音色](/api-reference/assets/voices/list-cloned-voices)、[重命名克隆音色](/api-reference/assets/voices/rename-cloned-voice)、[删除克隆音色](/api-reference/assets/voices/delete-cloned-voice)。

## 典型流程

```text
查询系统音色 → 选 voiceId → TTS
        或
声音克隆 → 响应/Webhook 中的 voiceId → TTS
```

合成语言见 [支持的语言](/zh/guides/supported-languages)。

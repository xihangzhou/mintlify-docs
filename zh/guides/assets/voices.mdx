音色仅属 API 侧，TTS 与音视频翻译通过 `voiceId` 引用，与 vmeg.ai 网页上的音色不互通。见 [资产概览](/zh/guides/assets/overview)。

## 两类音色

| 类型 | 来源 | API |
|------|------|-----|
| **系统（basic）** | 平台预设 | `POST /openapi/v1/assets/voice/basic/list` |
| **克隆（cloned）** | [声音克隆](/zh/guides/products/voice-clone) 成功 | `POST /openapi/v1/assets/voice/clone/list`、`update`、`delete` |

## `voiceId` 与 `provider`

列表或任务响应里，每条音色通常包含：

| 字段 | 系统预设 | 克隆音色 |
|------|----------|----------|
| **`voiceId`** | [列出系统音色](/zh/api-reference/assets/voices/list-system-voices) 返回的稳定 ID（如 `sv_…`） | 克隆列表或克隆任务返回的稳定 ID（如 `cv_…`） |
| **`provider`** | 预设档位代号 `S1`、`S2`、… | 克隆引擎 `V1`–`V5` |

**请原样使用 API 返回的值**，不要自行拼接或猜测。

- [文本转语音](/zh/guides/products/text-to-speech) 只需传 **`voiceId`**，无需传 `provider`。
- [音视频翻译](/zh/guides/products/media-translation) Webhook 里，翻译句可能同时带两个字段；若后续要改句或重提，**请把 `voiceId` 与 `provider` 成对保存**。

<Note>
  `S1`、`S2` 等是面向 API 的预设档位代号；`V1`–`V5` 是克隆引擎版本。它们不是厂商名或底层模型名。
</Note>

## 系统音色

列出可用预设，选取 `voiceId` 用于 [文本转语音](/zh/guides/products/text-to-speech)。

筛选与响应字段：[列出系统音色](/zh/api-reference/assets/voices/list-system-voices)。

## 克隆音色

声音克隆成功（同步响应或异步 Webhook）后，VMEG 持久化克隆并分配新 **`voiceId`**，可用于后续 TTS。

可通过 clone 资产接口重命名或删除。请求与响应字段：[列出克隆音色](/zh/api-reference/assets/voices/list-cloned-voices)、[重命名克隆音色](/zh/api-reference/assets/voices/rename-cloned-voice)、[删除克隆音色](/zh/api-reference/assets/voices/delete-cloned-voice)。

## 典型流程

```text
查询系统音色 → 复制 voiceId → TTS
        或
声音克隆 → 响应/Webhook 中的 voiceId → TTS
```

合成语言见 [支持的语言](/zh/guides/supported-languages)。

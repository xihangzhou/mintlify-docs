Open API **资产**是你在任务请求中通过 ID 引用的资源。两类：

| 资产 | ID 字段 | 用途 |
|------|---------|------|
| **素材（Material）** | `materialId` | 上传的音视频输入（主要用于媒体翻译） |
| **音色（Voice）** | `voiceId` | 系统预设或克隆音色，用于 TTS |

## 仅 API 侧存储

通过 API 上传或创建的素材、音色，与你在 [vmeg.ai](https://www.vmeg.ai/home) 网页上管理的文件、音色不互通，不能混用 `materialId` / `voiceId`。请仅用 `/openapi/assets/**` 管理。API 任务同样独立，见 [产品概览](/zh/guides/products/overview)。

## 典型流程

```text
上传素材 → materialId → 媒体翻译任务
声音克隆 → voiceId → TTS 任务
查询系统音色 → voiceId → TTS 任务
```

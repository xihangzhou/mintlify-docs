## API Key

所有 `/openapi/**` 接口都需要 **API Key**。

```http
Authorization: Bearer <your_api_key>
```

服务端将 Key 解析为 `projId`（项目 ID）。带 `projId` 的列表与详情请求须与 Key 绑定项目一致。

<Warning>
  勿在客户端或公开仓库中暴露 API Key。请使用环境变量或密钥管理服务。
</Warning>

## 创建与轮换

在 Dashboard <a href={apiKeyUrl}>API 配置</a>（侧栏 **API**）创建或轮换 Key。未登录请先 <a href={productUrls.signInToApiSettings}>登录</a>。

同一页面可配置异步回调的 **Webhook URL** 与 **Webhook Secret**。

<Info>
  API 配置面向付费用户，见 [价格](/zh/guides/pricing)。
</Info>

## 鉴权失败

HTTP 状态码 `401`，响应体示例：

```json
{
  "code": 401,
  "message": "Invalid or missing API Key",
  "data": null
}
```

完整错误码见 [错误码](/zh/guides/errors)。

## 集成所需路径

| 路径 | 鉴权 | 用途 |
|------|------|------|
| `/openapi/**` | Bearer API Key | 你的服务端集成 |
| Dashboard `/api/openapi/**` | 会话 JWT | 仅产品 UI |

服务端集成通常只需 `/openapi/**` 与 [Webhook 接收端](/zh/guides/webhooks)。

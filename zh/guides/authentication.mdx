## API Key

`/openapi` 下所有公开接口（任务、资产、任务管理）均需要 **API Key**。

在 `Authorization` 请求头中传递：

```http
Authorization: Bearer <your_api_key>
```

服务端将 Key 解析为 `projId`（项目 ID）。列表、详情等接口上的 `projId` 查询参数须与 Key 绑定的项目一致。

<Warning>
  请勿在客户端应用或公开仓库中硬编码 API Key。生产环境请使用密钥管理服务或环境变量。
</Warning>

## 创建与轮换

在产品 <a href={apiKeyUrl}>API 配置</a> 页面（侧栏 **API**）创建或轮换 API Key。未登录时请先 <a href={productUrls.signInToApiSettings}>登录</a>。

同一页面可管理异步回调的 **Webhook** URL 与 Secret。

<Info>
  产品中 **API** 入口（路径 `/open-api-setting`）面向付费用户开放。免费用户需先升级才能进入 API 配置。
</Info>

## 认证失败

HTTP 状态为 `401`。响应体示例：

```json
{
  "code": 401,
  "message": "Invalid or missing API Key",
  "data": null
}
```

完整列表见 [错误码](/zh/guides/errors)。

## 公开 API 与控制台路由

| 路径前缀 | 认证方式 | 用途 |
|-------------|------|---------|
| `/openapi/**` | Bearer API Key | 客户集成 |
| `/api/openapi/auth/**` | 控制台 JWT | Key 管理（产品 UI） |
| `/api/openapi/callback/**` | 控制台 JWT | Webhook 配置与 Ping |

集成场景通常只需 `/openapi/**` 与你的 [Webhook 接收端](/zh/guides/webhooks)。

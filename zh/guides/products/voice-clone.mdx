从样本音频创建可复用的 **克隆音色**。成功后 VMEG 分配 **`voiceId`** 并写入 [API 音色资产](/zh/guides/assets/voices)。

## 同步与异步

| 模式 | 接口 | 结果 |
|------|------|------|
| 同步 | `POST /openapi/v1/task/clone-voice/create` | HTTP 响应含 `voiceId` 与样本信息 |
| 异步 | `POST /openapi/v1/task/clone-voice/create-async` | [Webhook](/zh/guides/webhook-request)，`event` 为 `openapi-clone-voice`（`data.voiceId`） |

`create` 与 `create-async` 均须 [`X-Idempotency-Key`](/zh/guides/idempotency)；异步还须配置 [Webhook](/zh/guides/webhooks)。

## 流程

<Steps>
  <Step title="准备样本">
    按 API 参考 schema 提供参考音频（URL 或已上传字段）。
  </Step>
  <Step title="提交克隆">
    同步或异步 create；`provider` 见[支持的克隆方式](/zh/guides/supported-clone-methods)，`sampleLanguage` 见 [支持的语言](/zh/guides/supported-languages)。
  </Step>
  <Step title="使用 voiceId">
    在 [文本转语音](/zh/guides/products/text-to-speech) 请求中传入。
  </Step>
</Steps>

## 克隆之后

- 列表：`POST /openapi/v1/assets/voice/clone/list`
- 重命名：`POST /openapi/v1/assets/voice/clone/update`
- 删除：`POST /openapi/v1/assets/voice/clone/delete`

克隆音色仅能通过 API 资产接口使用，不会出现在 vmeg.ai 网页的音色列表中。见 [资产概览](/zh/guides/assets/overview)。

请求与回调 schema：**API 参考 → Voice clone**。

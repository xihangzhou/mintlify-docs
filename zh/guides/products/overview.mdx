每个 Open API **产品**都会创建带 `taskId` 的 **任务**。无论产品类型，都可通过统一任务接口查询与管理。

## 与网站任务分离

Open API 任务与在 [vmeg.ai](https://www.vmeg.ai/home) 网页上发起的任务 **不是同一套**，规则与 [API 资产](/zh/guides/assets/overview) 一致。

- 请仅用 `/openapi/tasks/**` 与 Webhook 跟踪 API 任务。
- 网站上的任务记录不包含 API 任务；网站任务也不能用 Open API 查询。

<Info>
  API Key 只对应 **Open API 的任务与资产**；网页端操作使用另一套存储。
</Info>

## 任务 API

| 操作 | 接口 |
|------|------|
| 列表 | `GET /openapi/tasks/list` |
| 详情 | `GET /openapi/tasks/detail` |
| 删除 | `POST /openapi/tasks/delete` |

请求与响应字段：[任务列表](/api-reference/tasks/list-tasks)、[任务详情](/api-reference/tasks/get-task-detail)、[删除任务](/api-reference/tasks/delete-task)。

## 同步与异步

| 产品 | 同步创建 | 异步创建 | 如何拿结果 |
|------|----------|----------|------------|
| [音视频翻译](/zh/guides/products/media-translation) | — | `POST .../media-translation/create-async` | 仅异步：Webhook |
| [文本转语音](/zh/guides/products/text-to-speech) | `POST .../tts/create` | `POST .../tts/create-async` | 同步：HTTP `data.results`；异步：[Webhook](/zh/guides/webhooks) |
| [声音克隆](/zh/guides/products/voice-clone) | `POST .../clone-voice/create` | `POST .../clone-voice/create-async` | 同步：响应中 `voiceId`；异步：Webhook |
| [文本翻译](/zh/guides/products/text-translation) | `POST .../translate/create` | `POST .../translate/create-async` | 同步：`data.items`；异步：Webhook |

### 异步集成清单

1. [API 密钥](/zh/guides/authentication)
2. [幂等](/zh/guides/idempotency) — 每个 `POST` 都携带 `X-Idempotency-Key`
3. [Webhooks](/zh/guides/webhooks) — 在 API 配置填写 URL，复制自动生成的 Secret；快速返回 2xx
4. 调用 `create-async` → 保存 `taskId`
5. 处理 [Webhook 请求体](/zh/guides/webhook-request) — 先看 `event`（`openapi-tts`、`openapi-translate` 等），再解析 `data`

### 同步集成

调用非 async 的 `create` 时携带 `X-Idempotency-Key`，从 HTTP `data` 读取结果。

## 任务类型

`taskType` 使用短代码：

| `taskType` | 产品 |
|------------|------|
| `vt` / `at` | 音视频翻译 |
| `tts` | 文本转语音 |
| `cloneVoice` | 声音克隆 |
| `textTranslation` | 文本翻译 |

枚举中有 `st`（字幕翻译），当前 **未** 作为独立 Open API 产品开放。

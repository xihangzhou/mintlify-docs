## Open API 积分消耗

积分在计费任务 **受理并处理** 时扣除（同步 `create` 或异步 `create-async`）。下表为 Open API 产品；计费规则与 VMEG 产品内一致，除非另有说明。

| Open API 产品 | 接口 | 计费单位 | 积分 |
|---------------|------|----------|------|
| [音视频翻译](/zh/guides/products/media-translation) | `POST /openapi/v1/task/media-translation/create-async` | 按源媒资时长（分钟） | **60 积分 / 分钟** |
| [文本转语音](/zh/guides/products/text-to-speech) | `POST /openapi/v1/task/tts/create`、`.../create-async` | 按输入文本字符数 | **约 2 积分 / 200 字符** |
| [声音克隆](/zh/guides/products/voice-clone) | `POST /openapi/v1/task/clone-voice/create`、`.../create-async` | 每次克隆成功 | **10 积分 / 个音色** |
| [文本翻译](/zh/guides/products/text-translation) | `POST /openapi/v1/task/translate/create`、`.../create-async` | 按源文字符数（所有 `segments[].text` 合计） | **1 积分 / 100 字符** |

### 按分钟计费的产品

**音视频翻译** 不足 1 分钟按 **1 分钟** 计费，与产品内其他按分钟功能一致。

**音视频翻译**（`vt` / `at`）按上传素材时长计费。流水线可选项（例如 **唇形同步**）会在基础翻译费用上 **叠加** 积分 — 例如唇形同步常见为在翻译基础上 **+60 积分 / 分钟**。实际扣费取决于 `create` 请求中的 `options`；余额不足会在受理阶段返回 `402`。

**文本翻译** 按源文字符数累计：每 **100 字符** 为 1 个计费单位（各片段 `text` 长度相加），**向上取整**。例如 1–100 字符扣 **1 积分**，101–200 字符扣 **2 积分**。单位单价默认为 **1 积分**，具体以产品配置为准。

**文本转语音** 按字符数累计（约每 200 字符 2 积分；不足部分按产品规则取整）。

**声音克隆** 按每次成功的克隆任务扣费（同步或异步），后续 TTS 使用该 `voiceId` 不再重复收取克隆费用。

### 本节未单独列出的消耗

Open API **素材** 相关接口（上传 URL、列表、删除等）与 **音色** 管理接口为任务支撑能力，不在上表中单列「按次扣费」。

## 积分不足

积分不足时返回 `402 Payment Required`，见 [错误码](/zh/guides/errors)。

## 网站与 API 计费

账户 **积分余额** 共用；网页端与 Open API 的消耗可能在明细中分开展示。API 任务请用 [任务 API](/zh/guides/products/overview) 跟踪，不会出现在 vmeg.ai 网页上的任务记录里。

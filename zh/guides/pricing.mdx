## 谁可以使用 API

Open API 面向 **付费用户**。免费账户访问 <a href={productUrls.apiConfiguration}>API 配置</a> 时会提示升级。

## 积分

- 通过付费方案购买或获得 **积分**。
- 每次 API 任务（TTS、翻译、声音克隆、音视频翻译）在受理并处理时会 **消耗积分**。
- **Dashboard 非 API 功能**的积分消耗遵循产品内单独规则，与 Open API 调用 **不是同一套消耗明细**。

积分不足时返回 `402 Payment Required`，见 [错误码](/zh/guides/errors)。

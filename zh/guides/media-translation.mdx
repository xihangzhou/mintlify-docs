## 任务类型

| taskType | 含义 |
|----------|---------|
| `vt` | 视频翻译 |
| `at` | 音频翻译 |

<Info>
  若请求 `at` 但素材为视频，服务端会执行 **视频翻译 (vt)**，并在 `data.requestedTaskType` 中保留你提交的原始类型。
</Info>

## 提交任务

`POST /openapi/task/media-translation/create-async`

必填请求头：`X-Idempotency-Key`

```json
{
  "taskType": "vt",
  "source": { "materialId": "mat_abc123" },
  "language": {
    "source": "zh-CN",
    "target": "en-US"
  },
  "options": {
    "voiceClone": { "enabled": true },
    "translate": { "enabled": true }
  },
  "extraData": { "orderId": "20260529001" }
}
```

`options` 覆盖声音克隆、ASR、翻译、分离、增强、口型同步等，与产品中 <a href={productUrls.videoTranslation}>视频翻译</a> 和 <a href={productUrls.audioTranslation}>音频翻译</a> 对齐。完整请求 schema 见 [API 参考](/zh/api-reference/introduction)。

## 响应与回调

立即响应示例：

```json
{
  "code": 200,
  "data": {
    "taskId": "tsk_...",
    "requestedTaskType": "vt",
    "createdAt": "..."
  }
}
```

最终交付物通过 [Webhook](/zh/guides/webhooks) 的 `data` 返回（URL、字幕等，取决于任务类型）。

## 前置条件

1. [上传素材](/zh/guides/materials) 获取 `materialId`
2. （可选）通过 API 列出音色，或在 <a href={productUrls.cloneVoice}>克隆声音</a> 管理克隆
3. 在 <a href={apiKeyUrl}>API 配置</a> 配置并验证 Webhook

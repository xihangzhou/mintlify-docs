## Webhook 是什么

**异步**任务完成时（TTS、文本翻译、声音克隆、音视频翻译），VMEG 向你配置的 URL 发送 **HTTP POST**。这是接收 **任务结果** 的方式 — `create-async` 的 HTTP 响应只确认受理（`taskId` 等）。

Webhook 是异步结果的 **投递机制**，不是独立产品。

## 为什么需要

| 未配置 Webhook | 已配置 Webhook |
|----------------|----------------|
| `create-async` 只返回 `taskId` | POST 请求体含完整交付物 |
| 需轮询 `GET /openapi/tasks/detail` | 任务完成时主动通知你的服务 |

生产环境异步集成应在调用 `*-create-async` 前配置 Webhook。

## 配置

在 Dashboard <a href={apiKeyUrl}>API 配置</a>（<a href={productUrls.signInToApiSettings}>登录</a>）：

1. 设置 **Webhook URL**（建议使用 HTTPS）。
2. 设置 **Webhook Secret**，用于 [签名校验](/zh/guides/webhook-verification)。

可在同一页面测试连通性（若产品提供）。

## 接收端要求

你的接口必须：

1. **快速返回 2xx**（数秒内）。重逻辑放入队列或后台 worker。
2. **校验签名**（对原始请求体）— 见 [Webhook 签名校验](/zh/guides/webhook-verification)。
3. **按 `taskId` 去重**（或业务键）。重试可能重复投递相同载荷。

非 2xx 或超时时，VMEG 会按退避策略重试。

## 在哪里看 payload

| 主题 | 指南 | API 参考 |
|------|------|----------|
| 信封与各任务 `data` | [Webhook 请求体](/zh/guides/webhook-request) | 各 `create-async` 的 **Callbacks → task.completed** |
| 全部回调变体 | — | **Webhooks → taskCallback** |
| 仅受理响应 | [产品概览](/zh/guides/products/overview) | 各 `create-async` 的 **Response** |

<Note>
  指南讲 **如何集成**；API 参考提供请求与回调的 **精确字段 schema**。
</Note>

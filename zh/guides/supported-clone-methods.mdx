在请求中传入 **`provider`**，取值为 `V1`–`V5`，用于选择声音克隆 / 合成引擎。与 [vmeg.ai](https://www.vmeg.ai/home) 网页端音视频翻译、声音克隆中的模型选项一致。

## 在哪些接口使用

| 产品 | 字段 |
|------|------|
| [文本转语音](/zh/guides/products/text-to-speech) | `create` / `create-async` 上的 `provider` |
| [声音克隆](/zh/guides/products/voice-clone) | 创建克隆音色时的 `provider` |
| [音视频翻译](/zh/guides/products/media-translation) | 启用克隆时 `options.voiceClone.provider` |

## 引擎版本

| `provider` | 模型 | 适用场景 |
|------------|------|----------|
| `V1` | 基础通用 | 简单克隆：短句、日常对话 |
| `V2` | 影视情感 | 影视、剧情、叙事 — 情绪起伏与语气细节 |
| `V3` | 英语优化 | 通用场景下 **英语** 音色更准、更自然 |
| `V4` | 增强情感 | 需要真实情绪与细腻语气变化的内容 |
| `V5` | 多语言通用 | **非英语** 及多语言音色 |

## 选型建议

| 内容特点 | 建议 `provider` |
|----------|-----------------|
| 短句、轻量使用 | `V1` |
| 影视、剧情、表演感强 | `V2` 或 `V4` |
| 以英语为主 | `V3` |
| 以非英语或多语言为主 | `V5` |

## 文本转语音：`provider` 与 `voiceId`

[文本转语音](/zh/guides/products/text-to-speech) 每次请求最多可在 `data[]` 中提交 50 条文本。每条需要 `voiceId`，且整个请求只设置一个顶层的 `provider`。请按以下规则组批，避免请求被拒：

**使用系统预设音色时，`provider` 必须与该音色一致。** 在 [系统音色列表](/zh/api-reference/assets/voices/list-system-voices) 中查看该音色的 `provider`，并在 TTS 请求中传入**相同**取值。例如音色标注为 `V3`，请求里就要写 `"provider": "V3"`。不一致时 API 会返回错误，并说明该音色需要匹配的引擎版本。

**不要在同一请求里混用系统音色与克隆音色。** 系统预设 `voiceId`（来自基础音色列表）和克隆 `voiceId`（来自[声音克隆](/zh/guides/products/voice-clone)）必须分开发起 TTS 请求。若放在同一个 `data[]` 批次里，API 会拒绝并说明两类音色不能合并组批。

**同一批次里若全是系统音色，`provider` 必须统一。** 一次请求中的所有系统音色必须属于同一引擎版本（`V1`–`V5`）。若需要的音色对应不同 `provider`，请拆成多次请求。混用不同 `provider` 时 API 会拒绝并说明原因。

**仅使用克隆音色时**，按内容特点选择 `provider`（见上文表格）。克隆音色与系统音色仍不能放在同一请求中。

<Note>
  语言 locale 见 [支持的语言](/zh/guides/supported-languages)。`provider` 表示 **克隆引擎**，不是语言代码。
</Note>

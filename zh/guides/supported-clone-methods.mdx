Open API 在音色列表、翻译结果与克隆请求中使用简短的 **provider 代号**，用于指定引擎类型，不对客暴露厂商或模型名称。

## 代号一览

| 代号 | 用途 | 常见出现位置 |
|------|------|--------------|
| **`S1`、`S2`、…** | 系统预设音色 | [列出系统音色](/zh/api-reference/assets/voices/list-system-voices)、音视频翻译逐句结果 |
| **`V1`–`V5`** | 克隆音色与克隆任务 | [声音克隆](/zh/guides/products/voice-clone)、克隆列表、启用克隆的音视频翻译 |

需要改句或再次提交时，请 **成对复制 API 返回的 `voiceId` 与 `provider`**（音视频翻译尤其如此）。见 [音色](/zh/guides/assets/voices)。

## 在哪些接口需要传 `provider`

| 产品 | 字段 |
|------|------|
| [文本转语音](/zh/guides/products/text-to-speech) | **无需传入** — 只传 `voiceId` |
| [声音克隆](/zh/guides/products/voice-clone) | 创建克隆时的 `provider`（`V1`–`V5`） |
| [音视频翻译](/zh/guides/products/media-translation) | 启用克隆时 `options.voiceClone.provider`（`V1`–`V5`）；若已选定预设档位，`selectedVoicesList` 可附带对应 `S*` 代号 |

## 克隆引擎（`V1`–`V5`）

创建克隆音色，或音视频翻译启用声音克隆时，传入 **`V1`–`V5`**。与 [vmeg.ai](https://www.vmeg.ai/home) 网页端克隆选项一致。

| `provider` | 适用场景 |
|------------|----------|
| `V1` | 简单克隆：短句、日常对话 |
| `V2` | 影视、剧情、叙事 — 情绪起伏与语气细节 |
| `V3` | 通用场景下 **英语** 音色更准、更自然 |
| `V4` | 需要真实情绪与细腻语气变化的内容 |
| `V5` | **非英语** 及多语言音色 |

### 选型建议

| 内容特点 | 建议 `provider` |
|----------|-----------------|
| 短句、轻量使用 | `V1` |
| 影视、剧情、表演感强 | `V2` 或 `V4` |
| 以英语为主 | `V3` |
| 以非英语或多语言为主 | `V5` |

## 文本转语音：`voiceId` 与组批规则

[文本转语音](/zh/guides/products/text-to-speech) 每次请求最多可在 `data[]` 中提交 50 条。

**请使用 [音色](/zh/guides/assets/voices) 接口返回的 `voiceId`。** TTS 请求中 **不要传 `provider`**。

组批规则：

**`voiceId` 必须有效。** 若不在您的系统或克隆库中，API 返回 `400`，并提示通过 `POST /openapi/v1/assets/voice/basic/list` 或 `POST /openapi/v1/assets/voice/clone/list` 获取。

**同一请求内音色须兼容** — 系统预设须同一档位（同为 `S*` 系列），克隆须同一引擎（同为 `V1`–`V5` 之一）。例如不能在同一请求中混用 `S1` 与 `S2`，或 `V1` 与 `V2`。

**`timbreRefAudio` 仅适用于克隆引擎。** 若批次中含 `timbreRefAudio`，该批须全部为克隆引擎（`V1`–`V5`），不能与系统预设 `voiceId` 混用。

示例错误文案见 [错误码](/zh/guides/errors) →「TTS 音色校验」。

<Note>
  语言 locale 见 [支持的语言](/zh/guides/supported-languages)。`provider` 表示 **引擎类型**，不是语言代码。
</Note>

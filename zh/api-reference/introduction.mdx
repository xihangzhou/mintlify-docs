title: "API 概览"
description: "VMEG Open API 接口组织方式"
---

API 参考页面由已发布的 [OpenAPI 3.1](https://mintlify.com/docs/api-playground/openapi/setup) 规范自动生成。

## 地址

| 用途 | URL |
|------|-----|
| 文档站 | [https://docs.vmeg.ai/api](https://docs.vmeg.ai/api) |
| API 基址（所有 `/openapi/**` 请求） | `https://api.vmeg.ai` |

交互式 Playground 会向 `https://api.vmeg.ai` 发送请求。

## 认证

所有 `/openapi/**` 接口使用 Bearer API Key。在 Playground 中填入 Key 即可试调。

## 接口分组

| 分组 | 说明 |
|-------|-------------|
| TTS | 语音合成（同步与异步） |
| 文本翻译 | 批量句子翻译 |
| 声音克隆 | 从参考音频克隆 |
| 媒体翻译 | 视频/音频本地化流水线 |
| 任务管理 | 列表、详情、删除 |
| 资产 - 素材 | 上传与素材库 |
| 资产 - 音色 | 系统音色与克隆音色 |

概念说明（幂等、Webhook、错误码）见 **指南** 标签页。

VMEG Open API 让你以编程方式运行语音与翻译任务：提交任务、管理素材与音色，并通过 Webhook 接收异步结果。

## 能力概览

<CardGroup cols={2}>
  <Card title="TTS" icon="volume-high" href="/zh/guides/quickstart">
    批量文本转语音，支持同步响应或异步回调。
  </Card>
  <Card title="文本翻译" icon="language" href="/zh/api-reference/introduction">
    单次请求最多 50 段，支持同步或异步。
  </Card>
  <Card title="媒体翻译" icon="film" href="/zh/guides/media-translation">
    视频与音频本地化（`vt` / `at`），配合 Webhook。
  </Card>
  <Card title="声音克隆" icon="microphone" href="/zh/api-reference/introduction">
    从参考音频创建可复用的克隆音色。
  </Card>
</CardGroup>

## 快速上手

<Steps>
  <Step title="获取 API Key">
    在产品中打开 <a href={apiKeyUrl}>API 配置</a> 创建或轮换 API Key。若未登录，请先 <a href={productUrls.signInToApiSettings}>登录</a>。
  </Step>
  <Step title="认证">
    每个 `/openapi/**` 请求携带 `Authorization: Bearer <api_key>`。详见 [认证](/zh/guides/authentication)。
  </Step>
  <Step title="调用 API">
    按 [快速开始](/zh/guides/quickstart) 完成首次 TTS 或翻译调用。异步任务需配置 [Webhook](/zh/guides/webhooks)。
  </Step>
</Steps>

## 约定

| 项目 | 说明 |
|------|------|
| 路径前缀 | `/openapi` |
| 响应结构 | `{ "code": 200, "message": "", "data": { ... } }` |
| 成功 | `code === 200`（业务码，非 HTTP 状态码） |
| 异步幂等 | 请求头 `X-Idempotency-Key`（`*-async` 创建接口必填） |

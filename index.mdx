The VMEG Open API lets you programmatically run speech and translation workloads: submit tasks, manage materials and voices, and receive async results via webhooks.

## Get started

<Steps>
  <Step title="Get an API Key">
    Open <a href={apiKeyUrl}>API Configuration</a> in the product and create or rotate an API Key. If you are not signed in, use <a href={productUrls.signInToApiSettings}>Sign in</a> first.
  </Step>
  <Step title="Authenticate">
    Send `Authorization: Bearer <api_key>` on every `/openapi/**` request. See [Authentication](/guides/authentication).
  </Step>
  <Step title="Call the API">
    Follow the [Quickstart](/guides/quickstart) for your first TTS or translation call. Async tasks require a [Webhook](/guides/webhooks).
  </Step>
</Steps>

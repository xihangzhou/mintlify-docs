The VMEG Open API lets you programmatically run speech and translation workloads: submit tasks, manage materials and voices, and receive async results via webhooks.

## Capabilities

<CardGroup cols={2}>
  <Card title="TTS" icon="volume-high" href="/guides/quickstart">
    Batch text-to-speech with sync responses or async callbacks.
  </Card>
  <Card title="Text translation" icon="language" href="/api-reference/introduction">
    Up to 50 segments per request, sync or async.
  </Card>
  <Card title="Media translation" icon="film" href="/guides/media-translation">
    Video and audio localization (`vt` / `at`) with webhooks.
  </Card>
  <Card title="Voice clone" icon="microphone" href="/api-reference/introduction">
    Create reusable cloned voices from reference audio.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Get an API Key">
    Open <a href={apiKeyUrl}>API Configuration</a> in the product and create or rotate an API Key. If you are not signed in, use <a href={productUrls.signInToApiSettings}>Sign in</a> first.
  </Step>
  <Step title="Authenticate">
    Send `Authorization: Bearer <api_key>` on every `/openapi/**` request. See [Authentication](/guides/authentication).
  </Step>
  <Step title="Call the API">
    Follow the [Quickstart](/guides/quickstart) for your first TTS or translation call. Async tasks require a [Webhook](/guides/webhooks).
  </Step>
</Steps>

## Conventions

| Item | Detail |
|------|--------|
| Path prefix | `/openapi` |
| Response shape | `{ "code": 200, "message": "", "data": { ... } }` |
| Success | `code === 200` (business code, not HTTP status) |
| Async idempotency | `X-Idempotency-Key` header (required on `*-async` create endpoints) |
